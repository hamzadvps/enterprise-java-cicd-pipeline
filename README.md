# Enterprise Java Build and Release Automation

## Project Overview

An enterprise-style CI/CD project that automates
the build, testing, code quality analysis,
artifact management and deployment of a Java
Spring Boot application.

## Technology Stack

- Git and GitHub
- Java 17
- Maven
- Jenkins
- SonarQube
- Nexus Repository
- Docker
- AWS EC2

## Project Objectives

- Automate Java application builds.
- Execute unit tests.
- Perform code quality analysis.
- Publish build artifacts to Nexus.
- Build and publish Docker images.
- Deploy applications to QA and Production.
- Implement rollback and failure notifications.

## Environments

- QA
- Production
